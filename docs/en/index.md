# grpc_frame

[![en](https://img.shields.io/badge/lang-en-red.svg)](https://ohara-lab-su.github.io/grpc_frame/en/index.html) [![ja](https://img.shields.io/badge/lang-ja-yellow.svg)](https://ohara-lab-su.github.io/grpc_frame/ja/index.html)

[GitHub repository](https://github.com/ohara-lab-su/grpc_frame/) · [Project documentation](https://ohara-lab-su.github.io/)

A Python gRPC framework for exposing a local control object's public methods through a dynamically constructed client proxy. It uses `Describe` and `Call` instead of requiring a separate protobuf method for each device operation.
